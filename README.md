# Electricity Price Forecasting

**Research portfolio project — electricity markets, statistical modelling and forecasting.**

This repository is a workspace for developing reproducible methods to analyse and forecast wholesale electricity prices, with particular attention to nonlinear dynamics, negative-price episodes, uncertainty and market-risk applications.

## Research profile

My work sits at the intersection of:

- **Applied mathematics & statistics:** stochastic processes, Markov chains, dependent-data inference, nonlinear time series and Monte Carlo evaluation.
- **Energy markets:** European Day-Ahead electricity prices, renewable generation, negative-price episodes and PPA exposure.
- **Quantitative implementation:** Python data pipelines, model evaluation, backtesting and decision-support prototypes.

## Research principles

- Respect the information set available at forecast time; avoid look-ahead leakage.
- Preserve native temporal resolution and do not fabricate quarter-hourly observations from hourly forecasts.
- Evaluate models chronologically, against transparent baselines.
- Document data provenance, assumptions, limitations and reproducibility.
